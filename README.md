Documentação: Projeto Hamei.pet
1. Identificação
Nome do Projeto: Hamei.pet

Autor: Evandro Luiz Pereira

Contexto: Projeto integrante do Desafio Extra do ciclo 2 da Carreira Tech - SCTEC.

Objetivo: Criação de uma landing page comercial para o setor pet, focada em organização de conteúdo e experiência do usuário.

2. Sobre o projeto
O Hamei.pet é um projeto de landing page desenvolvido para oferecer uma solução digital completa para o setor pet. O objetivo foi criar uma página que fosse, ao mesmo tempo, organizada visualmente e funcional para o usuário final, utilizando uma identidade visual focada em cuidado e confiança.

3. Como o site foi construído
Para que o site funcionasse de forma fluida e profissional, trabalhei em três pilares:

Estrutura (HTML): Organizei o código utilizando tags semânticas. Isso garante que o site seja bem compreendido pelos navegadores, o que é um cuidado essencial para quem quer programar com qualidade.

Visual (CSS): Para a identidade da marca, defini uma paleta de cores baseada no Verde (#2D5A27) e Bege (#B87333), que trazem um ar profissional e acolhedor. Utilizei Flexbox e Grid para garantir que o site funcione perfeitamente em qualquer tela. Também apliquei o aspect-ratio nos cards de serviço, garantindo que o layout mantenha o formato ideal em qualquer dispositivo.

Interatividade (JavaScript): Foquei em facilitar a vida do usuário. O site conta com um menu responsivo, um botão de "voltar ao topo" com navegação suave e uma validação no formulário de contato que avisa caso algum campo fique em branco antes do envio.

4. Como testar o site
Para ver o projeto em funcionamento, basta manter todos os arquivos (index.html, style.css, scripts.js e a pasta de imagens) juntos na mesma pasta e abrir o index.html em qualquer navegador.

5. Considerações Finais
Este projeto foi desenvolvido como um desafio prático para consolidar meus estudos. Como referência técnica, utilizei as aulas das trilhas rápidas do programa SCTEC, que foram fundamentais para que eu pudesse estruturar o código de forma organizada e eficiente. É um trabalho que reflete a aplicação prática do que venho estudando e a disciplina que aplico na minha rotina profissional, unindo rigor técnico e atenção aos detalhes para entregar uma solução digital bem estruturada.
